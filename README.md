-  **[BizMind AI — Market Intelligence Platform](https://github.com/Srushtibonde/bizMind-ai)**
  Autonomous AI agent combining real-time web search + RAG document analysis to generate professional market intelligence reports. Built with LangGraph, Groq LLaMA 3.3 70B, ChromaDB. Reduces manual research time by 90%. [Live Demo](https://huggingface.co/spaces/SrushtiB99/bizMind-ai)

-  **[NYC Taxi ETL Pipeline & Analytics Dashboard](https://github.com/Srushtibonde/nyc-taxi-etl)**

-  **[Smart AI Agent](https://github.com/Srushtibonde/smart-agent)**
